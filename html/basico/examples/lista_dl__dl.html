Elemento DL (Lista de Definición)

Glosario Técnico

HTML
Lenguaje de marcado para crear estructura de páginas web.
CSS
Lenguaje de estilos para diseñar y maquetar páginas web.
JavaScript
Lenguaje de programación que ejecuta lógica en el navegador del usuario.

Preguntas Frecuentes

¿Cómo instalo Node.js?
Ve a nodejs.org, descarga la versión LTS y sigue el instalador.
¿Qué es npm?
npm es el gestor de paquetes de Node.js que permite instalar librerías JavaScript.
